# AstrBot 插件：LLM输出净化与转图 (LLM Purifier)

## 简介
一个 AstrBot 插件，让 LLM 的回复在聊天窗口里始终保持可读：

- **纯文本回复**：过滤掉模型"内部思考"产生的大段英文独白，并清除 Markdown 标记，输出清爽纯文本。
- **复杂格式回复**：检测到数学公式、表格、代码块、嵌套列表等剥离后难以阅读的内容时，自动保留排版，并通过 AstrBot 官方文转图流程将整段回复渲染为图片发送。
- **交给官方机器人发送（可选）**：aiocqhttp 群聊中需要转图时，可改由同群的 QQ 官方机器人以原生 Markdown 主动发送，公式、表格、代码块直接由 QQ 客户端渲染。
- **假 @ 转真 @**：将 LLM 输出中的 `@昵称`、`@QQ号`、`[at:QQ号]` 等写法转换为真正的 `At` 消息组件。

## 功能

### 思考过程过滤
- 基于中英文字符比例分析，识别开头以英文为主的"思考分析"段落并剥离。
- 智能锁定第一段以中文为主的段落作为正式回复起点。

### Markdown 净化（纯文本回复）
- 移除粗体、斜体、行内代码、代码围栏、标题、引用、链接、列表标记等 Markdown 符号。
- 优化了数学表达式识别规则，避免误删算式中的星号。

### 复杂格式整段转图
命中以下任一格式时，保留 Markdown 排版并整段转图片发送（使用 AstrBot 官方文转图模板，可在 WebUI 中选择）：
- 数学公式：`$$...$$`、`\[...\]`、`\(...\)`、常见 LaTeX 命令、含命令或上下标的行内 `$...$`
- Markdown 表格与 HTML 表格
- 多行代码块（单行行内代码不触发）
- 多级嵌套列表

### 复杂格式交给官方机器人发送
QQ 官方机器人接口支持原生 Markdown（含表格、代码块和 LaTeX 公式），而 aiocqhttp 只能发纯文本或图片。启用后，aiocqhttp 群聊回复命中上述复杂格式时，由同群的官方机器人（`qq_official` 或 `qq_official_webhook`）以主动消息把原始 Markdown 发到群里，aiocqhttp 账号自己不再发送文本。

群映射：
- aiocqhttp 使用 QQ 群号，官方机器人使用群 openid，两者无法互查，需要在「群映射」中填写 `QQ群号:群openid`。只有填写了的群才会交给官方机器人发送，其余群照常转图。
- 群 openid 是官方机器人该群会话 ID（UMO）的最后一段，会话 ID 形如 `机器人ID:GroupMessage:群openid`。
- 请确认群号与 openid 对应同一个群，否则回复会发到其他群。

发送失败时自动回退为整段转图，该群在 5 分钟内不再尝试。

使用条件：
- 群主已为官方机器人开启「机器人主动在群聊内发言」。
- 官方机器人与 aiocqhttp 账号在同一个群，并运行在同一个 AstrBot 实例中。
- AstrBot 的官方机器人适配器支持群主动消息；不支持时自动转图。
- 仅群聊生效；私聊和其他平台仍按转图处理。
- 主动消息受平台频率限制（单群每分钟 20 条、每天 1000 条），超出时该次回复转图。

### 假 @ 转真 @
- 识别回复中任意位置的 `@昵称`、`@QQ号`、`@昵称(QQ号)`、`[at:QQ号]`、`[at:昵称]`、`{{AT:QQ号}}` 和 `[CQ:at,qq=QQ号]`。
- 昵称来源：群内最近发言者、消息中被 @ 的成员，以及 aiocqhttp 平台的群成员列表（群名片 / QQ 昵称，缓存 10 分钟）。
- 昵称按最长前缀匹配，`@小明你好` 能正确识别为 @小明 + “你好”。
- 只有成功找到 QQ 号时才转换；无法匹配的昵称会保留原文本。`@全体成员` 不会转换。

## 安装
1. 在 AstrBot 管理面板插件市场搜索安装，或将本插件目录放入 `data/plugins/` 下。
2. 重启 AstrBot 或在管理面板重载插件。

## 配置
在 AstrBot 管理面板的插件配置页可视化设置：

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| 应用范围 | 仅普通聊天回复 | 可选「普通聊天与插件触发的回复」（含其他插件 `event.request_llm` 的回复）；指令和固定文本不处理 |
| 移除思考过程 | 关 | 过滤开头以英文为主的无标签思考段落 |
| 净化 Markdown 格式 | 开 | 仅对未触发转图的纯文本回复生效 |
| 假 @ 转真 @ | 始终启用 | 自动将可识别的假 @ 转成真正的 At 组件 |
| 官方代发·启用 | 关 | 需要转图时改由同群的 QQ 官方机器人以 Markdown 主动发送 |
| 官方代发·群映射 | 空 | 每项 `QQ群号:群openid`；只有填写了的群才会交给官方机器人发送 |
| 官方代发·官方机器人的平台 ID | 空 | 留空使用第一个官方机器人平台；同时运行多个官方机器人时填写 |
| 转图·总开关 | 开 | 关闭后所有分类检测失效（官方代发也随之失效） |
| 转图·数学公式 / 表格 / 多行代码块 | 开 | 按类别控制哪些格式触发整段转图 |
| 转图·多级嵌套列表 | 关 | 存在缩进子列表项时触发 |
| 转图·图片格式 | png | png 无损最清晰；jpeg 体积更小 |
| 转图·JPEG 质量 | 90 | 仅 jpeg 生效（框架默认仅 40） |
| 转图·渲染缩放倍率 | ultra | 高倍率采样，文字更锐利 |
| 转图·视口宽/高 | 1080 / 900 | 宽度决定图片宽度与排版换行 |

转图使用的模板跟随 AstrBot 全局文转图设置；由插件直接调用官方渲染接口，不受全局 `t2i_word_threshold` 字数阈值限制（短公式回复也会转图）。
