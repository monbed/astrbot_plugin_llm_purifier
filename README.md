# AstrBot插件：思考与MD杀手 (Thinking & MD Killer)

## 简介
这是一个 AstrBot 插件，能够先过滤掉大型语言模型（LLM）过度“内部思考”而产生的大段纯英文内心独白，然后再清除最终回复里的 Markdown 格式，提取出最清爽纯净的纯文本内容。

## 功能
- **智能思考过程过滤**：基于中英文字符比例分析，精准识别全英文落笔的“思考分析过程”并将其无缝剥离。
- **保留正式回复**：智能侦测第一段真正富含中文的段落，直接跳转并锁定正式回复。
- **标签支持**：自动适配部分自带 `<think>...</think>` 标签的模型。
- **一键清除 Markdown**：智能移除包含粗体、代码块、链接、列表等多余的 Markdown 标记格式，输出纯文本。
- **防止误伤**：在移除 Markdown 格式时优化了数学表达式识别规则，避免误删计算算式中的星号。

## 安装
1. 将本插件目录（即 `astrbot_plugin_llm_purifier` 文件夹）放置在 AstrBot 的 `data/plugin_data/` （或相应插件存放目录）下。
2. 确保 `metadata.yaml` 已经被成功识别。
3. 重启 AstrBot 或在管理面板重载插件。

## 配置
本插件采用纯静态智能启发式规则，无需任何额外配置即可生效。
