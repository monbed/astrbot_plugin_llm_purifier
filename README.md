# AstrBot 插件：LLM输出净化与转图 (LLM Purifier)

## 简介
一个 AstrBot 插件，让 LLM 的回复在聊天窗口里始终保持可读：

- **纯文本回复**：过滤掉模型"内部思考"产生的大段英文独白，并清除 Markdown 标记，输出清爽纯文本。
- **复杂格式回复**：检测到数学公式、表格、代码块、嵌套列表等剥离后难以阅读的内容时，自动保留排版，并通过 AstrBot 官方文转图流程将整段回复渲染为图片发送。

## 功能

### 思考过程过滤
- 基于中英文字符比例分析，识别开头以英文为主的"思考分析"段落并剥离。
- 智能锁定第一段以中文为主的段落作为正式回复起点。

### Markdown 净化（纯文本回复）
- 移除粗体、斜体、行内代码、代码围栏、标题、引用、链接、列表标记等 Markdown 符号。
- 优化了数学表达式识别规则，避免误删算式中的星号。

### 复杂格式整段转图
命中以下任一格式时，保留 Markdown 排版并整段转图片发送（使用 AstrBot 官方文转图模板，可在 WebUI 中选择）：
- 数学公式：`$$...$$`、`\[...\]`、`\(...\)`、常见 LaTeX 命令、含命令或上下标的行内 `$...$`
- Markdown 表格与 HTML 表格
- 多行代码块（单行行内代码不触发）
- 多级嵌套列表

## 安装
1. 在 AstrBot 管理面板插件市场搜索安装，或将本插件目录放入 `data/plugins/` 下。
2. 重启 AstrBot 或在管理面板重载插件。

## 配置
在 AstrBot 管理面板的插件配置页可视化设置：

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| 移除思考过程 | 关 | 过滤开头以英文为主的无标签思考段落 |
| 净化 Markdown 格式 | 开 | 仅对未触发转图的纯文本回复生效 |
| 转图·总开关 | 开 | 关闭后所有分类检测失效 |
| 转图·数学公式 / 表格 / 多行代码块 | 开 | 按类别控制哪些格式触发整段转图 |
| 转图·多级嵌套列表 | 关 | 存在缩进子列表项时触发 |
| 转图·图片格式 | png | png 无损最清晰；jpeg 体积更小 |
| 转图·JPEG 质量 | 90 | 仅 jpeg 生效（框架默认仅 40） |
| 转图·渲染缩放倍率 | ultra | 高倍率采样，文字更锐利 |
| 转图·视口宽/高 | 1080 / 900 | 宽度决定图片宽度与排版换行 |

转图使用的模板跟随 AstrBot 全局文转图设置；由插件直接调用官方渲染接口，不受全局 `t2i_word_threshold` 字数阈值限制（短公式回复也会转图）。
